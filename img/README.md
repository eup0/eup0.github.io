# Мини-картинки для словаря

Добавьте сюда PNG или SVG файлы с названиями слов для замены emoji.

**Структура:**
- `ant.png` или `ant.svg` для слова "ant"
- `bat.png` или `bat.svg` для слова "bat"
- И т.д.

**Рекомендации:**
- Размер: 100x100 px
- Формат: PNG (24-bit) или SVG
- Имя файла должно совпадать с английским словом (например: `cat.png`, `dog.png`)

Если картинка не найдена, будет показана emoji из словаря.
